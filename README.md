# Innovara – Student Innovation Platform

Innovara is a web platform that helps students discover hackathons, showcase projects, and continue developing ideas beyond competitions.

## ✨ Features

- Browse hackathons
- Explore student projects
- Search and filter content
- Project detail pages
- Hackathon detail pages
- Leaderboard
- Student profiles
- Organizer dashboard
- Responsive modern UI

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- CSS
- npm

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/aishwarya030807/Hackathon-and-Project-Management-System.git
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open the URL shown in your terminal (usually `http://localhost:5173`).
